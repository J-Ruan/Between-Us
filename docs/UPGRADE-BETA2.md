# 从 beta.1 升级到 beta.2

本次实际比对确认：GitHub 发布的 beta.1 与 beta.2 使用不同的 Debug 签名，不能直接覆盖安装。数据库结构仍为 schema 1，加密备份格式未改变。

## 保留现有资料的升级步骤

1. 在旧版打开“我的 → 备份与导出”，设置至少 8 位备份密码并导出加密备份，保存到下载目录等应用外位置。记住密码，不要在聊天中发送密码。
2. 确认应用提示备份完成，且所选目录中有非空 `.shiyan` 文件。备份失败或提示超过当前 128 MB 上限时，**暂不要卸载旧版**。保留相册中的原始截图。
3. 只有完成备份后，才卸载旧版、安装 [beta.2 APK](https://github.com/J-Ruan/Between-Us/releases/download/v0.1.0-beta.2/app-debug.apk)。卸载会删除旧版私有目录与数据。
4. 新版首次进入后，先到“我的 → 备份与导出”填写原密码，再选择备份恢复。恢复要求资料库为空，因此不要先导入新图片。
5. 恢复后，从系统最近任务中划掉拾言，再重新打开，以重新加载已恢复截图的预览。
6. 聊天主要为简体时，在“我的”开启“将新识别结果整理为简体”。此项默认关闭，原始 OCR 始终保留；不能把文字转换视为识别准确率。
7. 打开原有聊天的“校对”，选择“重新识别原图（保留已有消息）”。新结果为待校对草稿，原有消息不覆盖；核对新结果后再自行删除旧的错误识别。

模型权重和应用偏好设置不包含在备份内：如原来安装了 Qwen 模型，需要重新侧载；昵称、深色模式和应用锁等设置需要重新选择。故事、消息、截图、摘要、事件、引用及其数据关联保留在备份中。

如果旧版安装来源是本地构建而非 GitHub Release，签名情况可能不同；可以先尝试覆盖安装。系统提示签名冲突时，不要直接清空资料或卸载，请使用上述备份迁移步骤。
