# 拾言 v0.1.0-beta.2 · 开发测试版

原生 Android，离线优先，无联网权限，模型单独侧载。包含聊天截图导入、Bundled 中文 OCR、人工校对、Room / SQLCipher、引用与收藏、手写故事、本地 LiteRT-LM 接口、分层整理后台任务、基础报告和 PDF / HTML / PNG 与加密备份。

## 本次修复：滚动长截图识别

旧版会将 1080×16000 等长截图按最长边缩到 3000 内，导致正文缩为原来的 1/8，中文笔画无法可靠识别。现在按原有文字尺度分段解码和 OCR，并用重叠区域保留分段边界文字。此次还处理透明图、灰度对比度与 EXIF 方向；不会默认改写文字。

针对原生中文模型偶发的简繁混用，新增“我的 → 将新识别结果整理为简体”（Android 10+）。这是**可选的文字转换，不代表原始 OCR 更准确**，默认关闭。启用后，原生识别保存在 `originalText`，整理后的待校对文字保存在 `text`；校对页面可对照原始结果。它不能修复“天／夭”等非繁简错字，仍需对照截图确认。

对于已经导入的截图，打开任一对应消息的“校对”，点击“重新识别原图（保留已有消息）”。新结果为待校对草稿；用户保存的文字、旧 OCR 和原图不会被覆盖。确认新结果后，可自行删除旧的错误结果。

## 安装

下载 `app-debug.apk`，在 Android 8.0+ 的 arm64 或 x86_64 设备允许安装未知应用后安装。对照 `SHA256SUMS.txt` 校验文件完整性。不含 Qwen 权重，安装方式见 README。Debug 签名仅用于测试，不同构建机器可能更换签名；卸载前必须备份数据。**从 beta.1 升级如果提示签名不兼容，不要直接卸载。请先在旧版导出加密备份，保存好密码与原始截图，确认备份文件已保存后再考虑卸载／安装／恢复。** 此修复未改变数据库 schema 1。

## 重要限制

- 这是开发测试版，不是完整任务书全部功能验收后的正式产品。请使用非敏感测试资料，保留原始数据副本。
- 尚未在荣耀 90 上验证 Qwen3-0.6B 加载、中文推理质量、取消响应、长时间发热、GPU 和大规模多级摘要端到端效果。GPU 禁用。代码集成不等于模型真机测试已通过。
- 年度故事书基于用户确认事件／收藏的年度精选，生成后仍需逐章审核；没有自动事实一致性证明。
- 没有头像设置、照片故事封面／章节插图、多模板卡片定制／系统分享以及完整章节排版编辑器。当前卡片为奶油色精选文本，PDF / HTML 为文字章节与基础导出。
- OCR 为坐标启发式，逐行识别后由用户合并拆分。未实现所有聊天软件布局的自动气泡识别；相邻重叠候选不会自动删除，逐图候选提示体验仍需改进。
- 原文修改会标记关联摘要失效，处理任务检测版本变化后要求按受影响日期新建任务；尚未自动调度整棵受影响摘要树重算。
- 关键词检索当前为 LIKE。普通 AI 检索每次最多 200 条原文；完整年度精选使用已生成的月度索引分批读取选定原文。
- UI 尚未使用 Paging，超大资料库的内存表现未验收。单个压缩备份上限 128 MB，解压上限 256 MB，目前采用内存加密，不适合大型图库。
- 截图仅存私有目录，没有逐文件应用级加密。数据库使用 SQLCipher 与 Keystore。导出的 PDF / HTML / PNG 是明文。
- WorkManager 受 Android 后台时限和省电策略约束；长任务中断后需在记忆管理继续。生成长篇故事的用户级断点管理仍需完善。

实际执行的构建、单元与集成测试结果见 `docs/TESTING.md`。没有真实运行截图时不会提供伪造截图。没有 Release / APK 的实际页面时，不应将本文件视为已发布证明。
